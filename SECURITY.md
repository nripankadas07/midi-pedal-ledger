# Security

Treat input files as untrusted. Retain documented caps; use an isolated low-privilege environment for hostile input. This parser is not a security boundary. The CLI does not contact services or launch external commands. Reports may contain identifiers or sensitive aggregates: review before sharing. Do not post secrets/exploit payloads publicly; use GitHub private vulnerability reporting if enabled or privately contact the owner through a published channel. CI/audits establish only their recorded scope.
